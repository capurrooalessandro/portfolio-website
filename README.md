# Sito Portfolio online - Alessandro Capurro
Portfolio personale da Front-end Developer: presenta progetti, competenze, studi e contatti in un’interfaccia moderna, accessibile e responsive.

## Caratteristiche
- **HTML5 semantico** con struttura chiara (header/nav/main/footer) e gerarchia titoli corretta
- **CSS moderno** (layout responsive con Flex/Grid, design tokens in `:root`, dark theme)
- **Accessibilità**: alt descrittivi, `aria-label` mirati, focus visibile, tap-targets adeguati
- **Performance-first**: font self-hosted (Inter Tight), immagini ottimizzate, caricamenti lazy dove opportuno
- **UI/UX**: CTA con link social, sezioni progetti con figure/figcaption, sezioni About/Skills pulite

## Stack
- **HTML5**, **CSS3** (custom, mobile-first)
- **JavaScript** vanilla (per interazioni minime)
- Font self-hosted, icone self-hosted (FontAwesome)
